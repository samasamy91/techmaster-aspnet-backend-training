# Task 04 - Querying, Filtering, Pagination & Reports

## Overview

This task extends the **Training Center API** by implementing production-style querying and reporting features using **ASP.NET Core Web API** and **Entity Framework Core**.

The goal is to build flexible endpoints that support searching, filtering, pagination, and business reports while following clean architecture principles.

---

# Technologies

- ASP.NET Core Web API (.NET 8)
- Entity Framework Core
- SQL Server
- LINQ
- Swagger / OpenAPI
- Postman

---

# Objectives

- Implement dynamic searching and filtering.
- Support pagination for large datasets.
- Return DTOs instead of EF entities.
- Build business reports using EF Core queries.
- Practice LINQ aggregation and projections.
- Produce production-ready API endpoints.

# Five Important Queries

## 1. Student Search

**Endpoint**

```
GET /api/students?search=mohamed
```

Allows searching students by full name, email, or phone number using case-insensitive matching.

**EF Core**

- Where()
- Contains()
- Select()

---

## 2. Pagination

**Endpoint**

```
GET /api/students?pageNumber=1&pageSize=10
```

Returns students in pages instead of loading the entire table.

**EF Core**

- CountAsync()
- Skip()
- Take()

---

## 3. Advanced Enrollment Filter

**Endpoint**

```
GET /api/enrollments?trackId=1&status=Active&paymentStatus=Paid
```

Builds queries dynamically. Each filter is applied only when its query parameter has a value.

**EF Core**

- IQueryable
- Conditional Where()
- Any()
- DTO Projection

---

## 4. Revenue by Track

**Endpoint**

```
GET /api/reports/revenue-by-track
```

Returns revenue generated by each training track together with enrollment count.

**EF Core**

- GroupBy()
- Sum()
- Count()

---

## 5. Dashboard Summary

**Endpoint**

```
GET /api/reports/dashboard-summary
```

Provides overall business statistics in a single response.

Returned information:

- Total students
- Total tracks
- Active enrollments
- Revenue
- Unpaid enrollments

**EF Core**

- Multiple CountAsync()
- SumAsync()
- Aggregate Queries
