# Task 01 - C# Logic Drill Pack

## Overview

This task contains 20 C# console application drills completed during Phase 01 of the TechMaster ASP.NET Backend Career Training.

The drills focus on strengthening programming fundamentals, including:

- Input validation
- Conditions
- Loops
- Methods
- Strings
- Arrays
- Lists
- Dictionaries
- Classes
- Basic business logic
