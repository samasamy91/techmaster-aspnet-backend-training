REST & HTTP

1-REST id Representational State Transfer the architecture style for building web APIs using standard HTTP methods 
treats data as resource accessed through URL like Products,Students and other exposed through RESTful endpoints like /api/students.

2-
	GET : Retrieves data without changing it
	Post : Create new resource
	Put : Update existing resource completely
	Patch : Update only specific fields of resource
	Delete : Remove resource

	ex:Get/api/students || Post/api/products to create new product

3-
	200 Ok : Request completed successfully
	201 Created : New resource created successfully
	204 No Content : Delete or update completed without returning data
	400 Bad Request : Invalid request, failed validation
	404 Not Found : Requested resource not exist

	ex: Creating student return 201 Created, search wirh id not found return 404 Not Found
